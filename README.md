Capture notes, organize topics, pin important references, and quickly retrieve meeting summaries.

## Features

- **Note Creation** — Write and format notes with rich content
- **Topic Organization** — Group notes by topics and categories
- **Pin Important** — Pin key references for quick access
- **Search & Retrieve** — Full-text search across all notes
- **Status Tracking** — Active, archived, and pinned states
- **Analytics View** — Note distribution and topic insights
- **Import / Export** — JSON-based notes portability

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Markup | HTML5 |
| Styling | CSS3 (Custom Properties, Grid, Flexbox) |
| Logic | Vanilla JavaScript (ES2022) |
| Storage | LocalStorage |
| Server | Python HTTP server (dev) |

## Getting Started

### Prerequisites

- Python 3.x (for dev server)
- Modern web browser

### Installation

```bash
git clone https://github.com/vizvasanlya/First.git
cd First/vizvasanlya-notes-app
```

### Run

```bash
npm start
```

Open [http://localhost:5173](http://localhost:5173)

### Docker

```bash
docker compose up --build
```
